# Backsmith Scoop bucket

Install the latest public Backsmith release:

```powershell
scoop bucket add sanketkudale https://github.com/SanketKudale/scoop-bucket
scoop install sanketkudale/backsmith
```

The manifest is synchronized hourly from the latest verified release at [SanketKudale/backsmith](https://github.com/SanketKudale/backsmith).
